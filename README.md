# 홍보자동화

가게 사진을 인스타그램용으로 바꾸고, 홍보 문구까지 만들어 주는 도구입니다.

## 하는 일

- `자료` 폴더의 jpg, png 사진을 1080 x 1080 정사각형으로 만듭니다. 가운데를 기준으로 자르기 때문에 사진이 찌그러지지 않습니다.
- 사진 오른쪽 아래에 로고(`로고.png`)를 작게, 약간 투명하게 넣습니다.
- 결과를 `완성/날짜` 폴더(예: `완성/2026-10-28`)에 `날짜_번호.jpg` 이름으로 저장합니다.
- `가게 정보.txt`와 `내 말투.txt`를 읽어서 인스타그램 문구를 `홍보문구.txt`로 만듭니다. (API 키가 있을 때만)
- 원본 사진은 건드리지 않습니다.

## 폴더 구성

| 이름 | 설명 |
|---|---|
| `자료/` | 사진, `로고.png`, `가게 정보.txt`, `내 말투.txt`를 넣는 곳 |
| `완성/` | 결과물이 날짜별 폴더로 쌓이는 곳 |
| `사진변환.py` | 사진과 문구를 만드는 프로그램 |
| `실행.bat` | 더블클릭으로 실행하게 해 주는 파일 |
| `사용설명서.txt` | 매주 사용하는 방법 |

## 준비

- Python 3.12
- 필요한 패키지: `pip install pillow anthropic`
- 문구 자동 생성을 쓰려면 폴더에 `.env` 파일을 만들고 아래 한 줄을 넣습니다. 이 파일은 저장소에 올라가지 않습니다.

```
ANTHROPIC_API_KEY=발급받은키
```

키가 없으면 사진만 변환하고 문구는 건너뜁니다.

## 실행

```
python 사진변환.py
```

Windows에서는 `실행.bat`을 더블클릭해도 됩니다.

자세한 사용법은 [사용설명서.txt](사용설명서.txt)를 보세요.
